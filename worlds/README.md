# Миры Gazebo

SDF миров хранятся здесь; модели, Blender-исходники, GLB и meshes — в `../models/`.
Сейчас поставляется `empty.sdf`, площадка 200×200 м. Дублирующих SDF мира в сервисе
и Blender-пакете нет. Образ копирует каталог в `/opt/uav/worlds`.

Для нового мира добавить `<name>.sdf` и ресурсы в `models/`, задать `WORLD_FILE`
и `WORLD_NAME` в `.env`, пересобрать gazebo-service и обновить контейнер.
Для браузерной карты нужен `models/<WORLD_NAME>/manifest.json`; Compose передаёт
его путь в Backend. Произвольной загрузки SDF через публичный API нет.

Плагины PX4/Gazebo и reset-семантика сохраняются: reset/reboot читают выбранный
исходный SDF и удаляют runtime-дроны. В будущем каждый мир имеет собственный SDF;
менять мир через новый публичный API в рамках этого переноса не добавлялось.
