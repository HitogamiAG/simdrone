# Frontend платформы дронов

React 19 + TypeScript 7 + Vite 8, Mantine 9, Three.js / React Three Fiber, react-rnd, TanStack Query и Zustand. Детали интерфейса и известные ограничения: [`docs/frontend-plan.md`](../docs/frontend-plan.md).

## Запуск

```sh
npm ci
npm run dev
npm test
npm run build
```

Vite слушает `0.0.0.0:5173` и проксирует `/api` и WebSocket в Backend `localhost:8003`. Production образ собирает приложение и раздаёт его nginx на порту 80; Docker Compose публикует порт 3000. Nginx проксирует `/api` в Backend. MediaMTX WHEP остаётся прямым адресом.

Vitest + React Testing Library выполняют компонентные проверки в jsdom. Playwright входит в зафиксированный стек для последующих браузерных сценариев с реальными сервисами; e2e-набор пока не добавлен.

## Реализовано

Одно desktop workspace: сворачиваемая панель, accordion для дронов/миссий/мира, запросы к read API, общий realtime WebSocket для поз всех дронов, pause/resume симуляции и оболочка resizable окон. Клиент считает подписчиков по каналам, повторяет действующие подписки после reconnect и раздаёт события карте и окнам; REST-поза используется до первого realtime-образца. Локальные `world.glb` и manifest пакета `empty` подключены к React Three Fiber: версия сверяется с Backend, `glb_to_gazebo` применяется один раз, 2D/3D камеры, zoom/fit и слои площадок/дронов отображаются в браузере. Площадки выбираются в диалоге и кликом на карте; направление spawn-frame и owner видны.

Создание дрона подключено к `/api/v1/world/spawn-pads`: форма требует явный выбор доступной площадки и отправляет `spawn_pad_id`; занятые площадки показывают владельца, координаты доступны только для чтения, конфликты приводят к обновлению каталога. Список дронов показывает закреплённую площадку. Пакет `empty` версии 1.1.0 включает две площадки. Сцена проверена в Chromium при 1440×900 с mock Backend ответами: загружен настоящий локальный GLB, переключены 2D/3D камеры, выбор маркера открыл форму с площадкой. Браузерная проверка с реальным Backend/Gazebo и координатная приёмка 2 см остаются открытыми.

Создание окон телеметрии, видео, логов и manual пока показывает оболочку/заглушку (окно телеметрии читает общий поток поз). Редактор миссий, lifecycle подтверждения, полная приёмка геометрии GLB против Gazebo, offboard, WebRTC и полные диагностические сценарии не реализованы.
